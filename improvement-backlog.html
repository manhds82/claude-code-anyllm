Auto-failover: bytt provider automatisk ved feil
vanskelig ✅ done
Når en provider returnerer 429 rate-limit eller 5xx, bytter proxy automatisk til neste tilgjengelige provider — uten at Claude Code merker noe. Du mister aldri en kode-sesjon til et ratelimit.

LiteLLM har innebygd model_fallbacks i litellm_config.yaml. Generer listen automatisk fra providers.conf basert på hvilke keys som er satt.
# Generert i litellm_config.yaml: model_list: - model_name: claude-proxy litellm_params: {model: openai/DeepSeek-V4-Flash, api_base: ..., api_key: ...} - model_name: claude-proxy-fallback-1 litellm_params: {model: openai/llama-3.3-70b, api_base: ..., api_key: ...} router_settings: model_group_alias: {claude-proxy: [claude-proxy, claude-proxy-fallback-1]}
Trạng thái: đã triển khai. Mọi provider có key được thêm vào cùng model_name group + router_settings (retry/fallback). Commit 091e604.
npx claude-bridge — null-friksjon distribusjon
middels ✅ done
Publiser som en npm-pakke. I dag krever onboarding git-klon, Python, setup-script og manuell path-konfigurasjon — 5–10 minutter. Med en npm-pakke: npx claude-bridge start --provider groq og alt skjer automatisk. 100 millioner npm-brukere kan ta det i bruk på 30 sekunder.
npx claude-bridge start --provider groq npx claude-bridge start --provider nvidia --key nvapi-... npx claude-bridge list-providers npx claude-bridge benchmark
Trạng thái: đã triển khai — package.json + bin/claude-bridge.js clone repo về ~/.claude-bridge lần đầu rồi forward args sang script gốc.
GitHub Actions-integrasjon: automatisk code review på hver PR
middels ✅ done
Kjør Claude Code i CI uten Claude Pro: automatisk code review, doc-generering eller test-skriving på hver pull request. Bruk Groq (gratis tier) eller Gemini Flash. Dette åpner en helt ny use case — verktøyet er ikke lenger bare for interaktiv utvikling.
# .github/workflows/claude-review.yml - name: Start claude-bridge run: npx claude-bridge start --provider groq --no-vscode & env: LLM_API_KEY_GROQ: ${{ secrets.GROQ_API_KEY }} - name: Run Claude Code review run: claude --print "Review the diff and suggest improvements" env: ANTHROPIC_BASE_URL: http://localhost:4000 ANTHROPIC_AUTH_TOKEN: dummy
Trạng thái: đã triển khai trong .github/workflows/claude-review.yml, đã fix lỗi YAML (B-04) nên job đã chạy được thật; test suite chạy matrix ubuntu+windows.
Task-aware model routing: rett modell til rett oppgave
vanskelig ✅ done
Klassifiser prompten automatisk (enkel spørsmål / kode-edit / kompleks analyse) og rut til riktig modell — billig og rask for enkle ting, best tilgjengelig for komplekse edits. Kutt kostnader 60–80% uten å ofre kvalitet der det teller.

LiteLLM-router støtter allowed_model_region og rpm_limit per modell; legg til en liten klassifiserings-interceptor foran proxyen.
Trạng thái: đã triển khai khác cách đề xuất — dùng router-middleware.py (FastAPI, port 4001) ước tính token count và rewrite model field trước khi forward tới LiteLLM, thay vì phân loại độ khó câu hỏi. Kích hoạt qua --route/-Route + config/routing.conf.

Pre-flight key validation: vet hva som fungerer før oppstart
lett ✅ done
Før proxyen startes: send en billig GET /models-request til hver provider som har en key satt. Vis tydelig hvilke som er gyldige. Eliminerer "proxy krasjet stille" — det vanligste mystery-problemet.
.\start-claude.ps1 --check-keys # Output: [OK] fpt DeepSeek-V4-Flash key: LLM_API_KEY_FPT [OK] groq llama-3.3-70b key: LLM_API_KEY_GROQ [!] nvidia qwen2.5-coder-32b key: IKKE SATT [X] gemini gemini-2.5-flash 401 Unauthorized — sjekk key
Trạng thái: đã triển khai — -CheckKeys/--check-keys test từng provider có key trước khi start proxy.
Delt team-proxy: én server, mange devs

# På serveren: docker run -e LLM_API_KEY_GROQ=... -p 4000:4000 \ ghcr.io/manhds82/claude-bridge:latest # Hver dev setter i ~/.zshrc: export ANTHROPIC_BASE_URL="http://192.168.1.100:4000" export ANTHROPIC_AUTH_TOKEN="team-shared-dummy"
Trạng thái: chỉ làm một phần. Dockerfile/docker-compose.yml có sẵn (chạy proxy trong container), nhưng chưa publish image lên GHCR và chưa có docs riêng cho kịch bản "1 server dùng chung cho cả team".

Bedre feilmeldinger med handlingsrettede hints
lett ✅ done
Parser den faktiske provider-feilen (rate-limit window, ugyldig modellnavn, billing-kvote) og viser en konkret hint i terminalen — ikke bare "proxy krasjet, sjekk loggen". De vanligste feilene håndteres: 401, 429, 404 modell-ikke-funnet, nettverksfeil.
[X] Groq returnerte 429 — rate limit nådd. Prøv igjen om 43 sekunder, eller bytt provider: .\start-claude.ps1 -Provider fpt [X] Gemini: 401 Unauthorized LLM_API_KEY_GEMINI ser ut til å være utgått. Generer ny key: https://aistudio.google.com/apikey
Trạng thái: đã triển khai (bash) — khi proxy timeout, đọc log file và detect 401/429/ImportError/connection error để in hint cụ thể.
